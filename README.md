# Medusa Record — téléchargements

Medusa Record guide l'enregistrement d'un **clip a cappella en mosaïque** : une voix par prise, de 1 à 99 vignettes
synchronisées, mixées et exportées en MP4.

Ce dépôt ne contient **aucun code** : seulement les installeurs, dans l'onglet
[**Releases**](../../releases).

## Installer (Windows 10/11, 64 bits)
1. Ouvrir la dernière [Release](../../releases/latest) et télécharger `MedusaRecord-<version>-setup.exe`.
2. Le lancer. Windows peut afficher « Windows a protégé votre ordinateur » (le logiciel n'est pas signé) :
   cliquer sur **Informations complémentaires** puis **Exécuter quand même**.
3. Le logiciel s'installe dans votre profil (aucun droit administrateur), avec un raccourci sur le Bureau et dans le
   menu Démarrer. Pour le retirer : Paramètres › Applications › Medusa Record › Désinstaller (vos clips et réglages
   sont gardés).

Sans installation : le `.zip` de la même Release, à décompresser, puis lancer `Medusa Record.exe`.

## Il faut
- une caméra et un micro ; **un casque** pour entendre les prises déjà faites sans qu'elles repassent dans le micro.

## Versions
- **Pre-release** = version de test (UNSTABLE) ; **Latest** = version stable.

ffmpeg est fourni avec le logiciel (build de gyan.dev, licence GPL, texte dans `resources\bin\ffmpeg-LICENSE.txt`).
